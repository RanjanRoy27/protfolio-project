# Hero Animation Architecture Notes

## Layout idea
- Left side: eyebrow, headline, supporting text, CTA buttons.
- Right side: visual card or mockup area.

## Animation idea
- Use a lightweight text-cycle or clip-style reveal effect.
- Keep motion subtle and readable.
- Use CSS keyframes for the hero animation.

## File ownership
- HTML hero section: main site file.
- CSS animation styles: separate experiment styles in the same branch.
- Reference assets: assets/hero-reference/
